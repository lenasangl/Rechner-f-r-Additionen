# Rechner für Additionen

Die Aufgabe bestand darin, einen fehlerhaften „Chaos-Kalkulator“ zu reparieren und zu erweitern. Du solltest eine kleine Webanwendung erstellen, die zwei Zahlen entgegennimmt und eine verzögerte Berechnung durchführt. Dabei musstest du Fehler korrekt abfangen (mit throw, try/catch/finally), eine Callback-Funktion einsetzen sowie mindestens eine asynchrone Funktion mit Promise oder async/await verwenden. Außerdem sollte das Layout mit Flexbox gestaltet und responsive sein. Zusätzlich waren zwei kreative Erweiterungen Pflicht, z. B. mehrere Rechenarten, Farbreaktionen oder Emojis. Am Ende sollte eine kurze Reflexion über Herausforderungen und Lernfortschritte verfasst werden.
